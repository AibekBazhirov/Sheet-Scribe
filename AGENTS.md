# Repository instructions

## Codex and Claude Code collaboration

- Before editing, check the current branch, working tree, and latest changes on GitHub. Preserve work in progress.
- Use a GitHub issue to coordinate shared work. Record who is implementing it and use a separate branch and pull request for the change.
- In the pull request, link the issue and record what changed, what you verified, and any remaining work. The other assistant can review the PR or continue after an explicit handoff.
